## 一、问题陈述

星落之夜 v1.0 是一个纯 HTML/CSS/JS 互动视觉小说，上线 GitHub Pages 后获得不错反响（零安装、32KB 极致体积、精美暗色调 UI）。但核心问题是**留不住人**：

1. **重玩性为零** — 线性分支剧情，看一遍就完了
2. **关系系统浅** — 3 维好感度只影响结局文字，不影响过程
3. **无持续交互** — 没有日历、日程、养成系统推动玩家每天回来
4. **内容消耗快** — 10 分钟通关，玩家没有理由再打开

对标项目 Heartmorrow（https://github.com/HMDSimDev/heartmorrow）通过 LLM 实时对话 + 日历系统 + 7 维关系 + 社交图谱实现了无限重玩性。但 Heartmorrow 需要本地 LLM 服务器 + Node.js 环境，门槛极高。

**机会点：** 在保留"浏览器即开即玩"零门槛优势的前提下，通过预写多态内容 + 状态驱动引擎，实现类 Heartmorrow 的深度和重玩性。

**一句话：** 让星落之夜从"看一个故事"变成"活在一个世界"，但依然零安装、零后端。v2.0 聚焦多态剧情引擎 + 深度关系系统 + 日历生活模拟。LLM 集成将在 v2.x 路线图中作为可选增强。|

## 三、目标用户

### 主要用户画像

**P1 — 轻量故事玩家（70%）**
- 年龄：16-28 岁
- 习惯：刷手机，玩互动叙事游戏
- 痛点：不想安装任何东西，玩完即走
- v2 价值：更深的故事体验，但依然零安装

**P2 — 收集型玩家（20%）**
- 年龄：20-35 岁
- 习惯：全成就党，多结局收集者
- 痛点：v1 只有 2 个结局变体，没动力
- v2 价值：8+结局、20+成就、回忆相册

**P3 — 视觉小说爱好者（10%）**
- 年龄：18-40 岁
- 习惯：玩过心跳文学部、星露谷物语等
- 痛点：想要有深度的关系养成
- v2 价值：7维关系系统 + 日历事件

## 五、约束条件

1. **零后端约束** — 不得引入任何服务器端组件。所有逻辑必须在浏览器端执行
2. **纯前端 LLM 约束** — 不得强制用户提供 LLM API Key。AI 辅助功能必须为可选
3. **文件大小约束** — 全量资源（含图片）≤ 500KB。核心引擎 ≤ 100KB
4. **离线可运行** — 所有功能在 offline 状态下可用（除非显式标注需要网络）
5. **GitHub Pages 兼容** — 纯静态部署，无 SSG/SSR 需要
6. **浏览器兼容** — 支持 Chrome/Firefox/Safari 最近 2 个主版本
7. **移动端优先** — 触摸操作必须流畅，不比桌面端体验差
